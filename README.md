# OLIST_Ecommerce_DE-DA-Fabric-Project
End-to-End Data Engineering &amp; Analytics Project using Microsoft Fabric, PySpark, Medallion Architecture, Data Factory Pipelines, Semantic Model and Power BI.

# Dataset

This project uses the Brazilian E-Commerce Public Dataset by Olist.

The original public dataset was used for the historical period.

Additional synthetic data was generated for 2019–2026 to simulate a larger production environment and support:

- ETL scalability testing
- Year-over-year analysis
- Pipeline orchestration testing
- Power BI time intelligence
- Dashboard performance validation

Raw datasets are not stored in this repository.
