# Power BI Executive Dashboard

## Overview

The Executive Dashboard provides a consolidated view of the main business performance indicators from the Olist e-commerce analytical model.

The report is built on top of the Power BI semantic model using Gold-layer fact and dimension tables created in Microsoft Fabric.

---

## Business Purpose

The dashboard is designed to provide a high-level view of commercial performance, customer activity, fulfillment performance, and customer experience.

It allows users to analyze performance by:

- Year
- Month
- Quarter
- Product Category

---

## Key Performance Indicators

The dashboard includes the following KPIs:

- Total Revenue
- Total Orders
- Total Products Sold
- Total Customers
- Average Order Value
- Average Review Score
- On-Time Delivery Rate

---

## Analytical Views

The dashboard also provides analysis of:

- Revenue trends by month
- Current-period versus previous-period performance
- Revenue by product category
- Top sellers by revenue
- Regional sales performance
- Order status distribution
- Delivery performance
- Customer review performance

## Report Implementation

The Executive Dashboard was developed in Power BI on top of a Microsoft Fabric semantic model.

The report integrates multiple analytical domains into a single executive view, including sales performance, customer activity, delivery performance, regional analysis, seller performance, and customer reviews.

The semantic model is hosted in a managed Microsoft Fabric environment. Therefore, the portfolio provides a dashboard screenshot and interaction demo rather than distributing a live-connected PBIX file.
